# Actualización del cliente a 1.7.0

Actualiza primero el servidor autoalojado a `1.7.0`. El cliente `1.7.0` envía el token de sesión en todas sus peticiones, que es lo que ese servidor exige.

> [!IMPORTANT]
> El **servidor `1.7.0` no admite un cliente anterior**. Si actualizas el servidor y no este cliente, la aplicación mostrará errores al cargar o guardar mediciones. En el sentido contrario no hay problema: este cliente funciona también con servidores `1.6.1` o anteriores, porque la cabecera adicional se ignora.

## Resumen de cambios

- El cliente envía la cabecera `X-Session-Token` en **todas** las peticiones de datos, no sólo al importar o restaurar copias.
- Si el dispositivo pierde el token guardado, la aplicación lo advierte y pide volver a iniciar sesión en lugar de mostrar un fallo genérico.
- Se elimina código sin uso de la capa de datos antigua; no cambia ninguna pantalla.

## Instalación

- **APK Android.** Instálalo encima de `1.6.1` sin desinstalar: la firma no ha cambiado. Si vienes de `1.6.0` o anterior, sigue primero el aviso de [la nota de 1.6.1](v1.6.1.md), que exigía desinstalar.
- **PWA.** Se actualiza sola al abrirla. No borres los datos del sitio.
- Si publicas tu propia copia en un dominio distinto de los admitidos, declara ese origen en `CORS_ORIGINS` del servidor.

## Comprobar

Abre la aplicación, comprueba que el indicador de servidor aparece en verde, que carga el historial y que guarda una medición de prueba. El panel de estado detallado sólo está disponible para administradores.
